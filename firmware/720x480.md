# Configuring 720 x 480 @ 60 Hz

This markdown file describes how to configure this resolution on both
the HDMI and DPI outputs.

This configuration was developed for Raspberry Pi OS Lite (32-bit),
based on Debian 13 'Trixie'.

The end of the file `/boot/firmware/config.txt`, it says 

```
[all]
```

Edit it to say: 
```
[all]
# 24-bit RGB888 DPI output on GPIO 0-27 (8 bits per channel)
dtoverlay=vc4-kms-dpi-generic,rgb888,hsync-invert,vsync-invert
dtparam=hactive=720,hfp=16,hsync=62,hbp=60
dtparam=vactive=480,vfp=9,vsync=6,vbp=30
dtparam=clock-frequency=27000000

# Put the USB port in device (gadget) mode, for serial login
dtoverlay=dwc2,dr_mode=peripheral
```
You also have to edit  `/boot/firmware/cmdline.txt`.

My version initially said:
```
console=serial0,115200 console=tty1 root=PARTUUID=a090f466-02 rootfstype=ext4 fsck.repair=yes rootwait ds=nocloud;i=rpi-imager-1793106770088 cfg80211.ieee80211_regdom=PL
```

Don't copy it, you will have a different Partition Unique Id (PARUUID). 
Just add the following two values at the end of the line. modules-loa

modules-load=dwc2,g_cdc video=HDMI-A-1:720x480@60D

Here is what they do:

- **modules-load=dwc2,g_cdc** It makes the Zero's USB port act as a USB serial port and network adapter when it's plugged into the Mac, so you can log in over the cable.

- **video=HDMI-A-1:720x480@60D** sets the Pi's mini-HDMI output to 720×480 at 60 Hz, the same as DPI. The D keeps the output on even when no monitor is detected.

For the changes to take effect you need to reboot.  Please run: 

```
sudo reboot
```
And wait for the changes to take effect. On my device I have to wait 2 minutes and 49  seconds for a reboot.

If you want to access the device over a usb tty, you also need to
start a program which will respond to such input.

```
sudo systemctl enable serial-getty@ttyGS0.service
```
