## Configuring the firmware (July 2026)

# Booting

A new Raspberry Pi Zero W (RPI) needs the operating system loaded onto
the SD card using an SD card reader, and the card needs to then be
inserted into the RPI's SD card slot.  RPI memory is limited, so it is
recommended to install the Raspberry Pi Lite operating system, rather
than the desktop version. That will leave more RAM for any image you
may wish to display later.  The installer program can automatically
configure wifi, so it is recommended to use that option. That makes it
possible to downlaod and install additional software on the RPI, such
as your favorite text editor. You may want to also configure the USB
serial port for desktop connectivity for when you do not have
wifi access. These are all standard operations well documented elsewhere.

# Configuring

There are three parts to configuring the firmware for this application

1. Configuring DPI
2. Configuring HDMI (for testing the RPI)
3. Configuring the camera
4. Configuring test patterns generated by software

## DPI and HDMI

In this directory you will find files with names like `720x480.md`.
That file contains instructions for configuring the RPi for 720x480
DPI and HDMI output.

# USB

To configure serial access over the USB cable, add these two lines to
the end of `/boot/firmware/config.txt`. It should be after the DPI and
HDMI configuration.
```
# Put the USB port in device (gadget) mode, for serial login
dtoverlay=dwc2,dr_mode=peripheral
```

## Camera Configuration
In this directory is a file called Camera.md.  It provides instructions 
for enabling the camera input.  As soon as my next camera arrives, those 
instructions will be tested, in the meantime I am working with images 
generated in software. 


There are three files which need to be changed to connect to the RPI
Zero over usb.

- cmdline.txt	
- config.txt	
- user-data

Be careful to not copy a `cmdline.txt` file from elsewhere.  It has a
hard wired PARTUUID, which is a particular way of identifying a
drive. The PARTUUID changes every time the Raspberry Pi Imager formats
an SD card so always start with the version of `cmdline.txt` generated by
the Raspberry Pi Imager, and then make the following change. Append:
```
modules-load=dwc2,g_ether
``` 
after rootwait resize. It should be on the same line. 

## Test Patterns
While waiting for a RPi compatible camera to arrive, a test pattern generator 
can be used to test the rest of the system. A number of test pattern 
generators are available. It is also possible to display a stored image.
