# Configuring the firmware (July 2026)

## Booting

A new Raspberry Pi Zero W (RPI) needs the operating system loaded onto
the SD card using an SD card reader, and the card needs to then be
inserted into the RPI's SD card slot.  RPI memory is limited, so it is
recommended to install the Raspberry Pi Lite operating system, rather
than the desktop version. That will leave more RAM for any image you
may wish to display later.  The installer program can automatically
configure wifi, so it is recommended to use that option. That makes it
possible to download and install additional software on the RPI, such
as your favorite text editor.

## Test Patterns
While waiting for a RPi compatible camera to arrive, a test pattern generator 
can be used to test the rest of the system. A number of test pattern 
generators are available. It is also possible to display a stored image.
