## Configuring the firmware (July 2026)

There are three files which need to be changed to connect to the RPI
Zero over usb.

- cmdline.txt	
- config.txt	
- user-data

As long as this is the same Raspberry Pi OS (Debian 13 'Trixie'),
flashed July 2026.  you can just use
the provided versions of `config.txt`, and `user-data`. **Do not
reuse** an existing `cmdline.txt`.  It has a hard wired PARTUUID,
which is a particular way of identifying a drive. The PARTUUID changes
every time the Raspberry Pi Imager formats an SD card So always copy
the version of `cmdline.txt` generated by the Raspberry Pi Imager, and
then make the following change. Insert: `modules-load=dwc2,g_ether`
afterrootwait resize.  There should be no newline.
