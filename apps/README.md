## ECPI Applications

It is expected that a number of ECPI apps will soon be crowdsourced. 

- **[RGB888](rgb888)**: The initial application. 
  Tranmits 640 * 480 DPI data.
- **RGB788**: The low order red bit is replaced with the RPI Oscillator.
- **RGB787**: The low order red and blue bits are replaced with a UART.
- **RGB666**: The two low order RGB bits are replaced with a quad SPI.
