# AI POLICY

AI is terrible at writing code, but past brilliant at code reviews.  I
believe it is particular bad at writing Verilog because it is not
thinking about the circuit design while it is doing so.  Accordingly
AI is used for answering questions, and for code reviews, but not for 
writing. 

That is not quite true.  Sometimes I let it write a few lintes of
code.  Usually an obscure linux command, or setting a few
configuration parameters.
