# AI POLICY

AI is terrible at writing code, but past brilliant at code reviews.
AI is particular bad at writing Verilog because it is not thinking
about the circuit design while it is doing so.  Accordingly AI is used
for answering questions, and for code reviews, but not for writing code 
nor text.

A huge advantage of AI doing code reviews is that the author's 
coding skills improve. 

AI is much better than I am at technical drawing, so it is used for 
documentation drawings. 

I apologize, there were a few instances where the AI wrote a few lines of 
code, typically RPi Linux configuration commands.   When such code is spotted,
it is carefuly tested and reviewed and an attribution comment is added
